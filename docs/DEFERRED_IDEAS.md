# قائمة الأفكار المؤجَّلة — درب

> قاعدة: أي فكرة جديدة لا تُنفَّذ الآن، بل تُحفظ هنا. لا نبني أي طبقة قبل أن
> يستخدمها طالب حقيقي، وأي قرار تصميمي يجب أن يخدم **قاعدة المعرفة الموحّدة**.

## العقل (Life Engine) — مُجمَّد ❄️
وصل ٩٥٪ في مصفوفة التحقّق ورُبِط بالصفحات بصمت. **لا تطوير إضافي حتى إشعار آخر.**
الطبقات التالية مؤجَّلة (تُبنى فقط حين نحتاجها ويكون لها مصدر بيانات حقيقي):

- **Weights** — أوزان علاقات مخصّصة لكل طالب (تحتاج «هدفك»: الشركة/الوظيفة المطموحة).
- **Confidence صريحة** — «أعرف ETAP/MATLAB» (تحتاج سطح إدخال لما يتقنه الطالب).
- **Prediction** — توقّع حاجة الطالب قبل بحثه (تحتاج سلوكاً متراكماً أولاً).
- **targetCompany / أحب أرامكو** — حقل هدف في التسجيل يغذّي الأوزان.

## أفكار منتج مؤجَّلة
- ربط عقدة أولوية الطالب بشبكة التخصص (إبراز العقدة وترتيبها حولها).
- توسعة الشبكة عبر الطبقات (جامعة ← كلية ← تخصص ← الشبكة) للدخول من الجامعة.
- مدير المواد الذكي (إضافة مادة → ربط تلقائي بالأدوات/المشاريع/الشركات).

---
*تُراجَع هذه القائمة بعد اكتمال خطة المحتوى الرسمية (قاعدة المعرفة → الكتب →
الإنجليزية/STEP → التحصيلي/القدرات → السرعة والتجربة).*
